# argong-ai-skill-assets

디엔소프트(알공) 조직 AI 스킬의 이미지 에셋 공개 미러입니다.
gbrain 메모리 `Ai Skill` 도메인(`ai-skill/index`)의 스킬 페이지가 이 URL들을 참조합니다.

- `brand-kit/base64-assets/` — 알공 브랜드킷 `references/assets-base64.json`을 디코딩한 원본 이미지 (키 이름 = 파일명)
- `brand-kit-books/base64-assets/` — 알공북스 브랜드킷 base64 에셋 디코딩본
- `brand-kit-books/assets/` — 알공북스 브랜드킷 원본 에셋 폴더
- `manifest.json` — 스킬별 파일 목록과 raw URL

URL 형식: `https://raw.githubusercontent.com/dn-soft/argong-ai-skill-assets/main/<path>`
